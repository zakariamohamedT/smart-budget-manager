# smart-budget-manager
A project for managing Budget
This mini-project proposal outlines the development of the Student Attendance Management System
(SAMS), an automated web application engineered specifically for ESI-SBA. By replacing conventional manual
paper registers with a centralized digital portal, SAMS enables instructors to record session attendance rapidly,
calculates cumulative student absence metrics automatically, and enforces academic exclusion regulations
transparently. The project will be realized in 12 weeks with an estimated budget of 450,000 DZD.
